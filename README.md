## Descripción del Proyecto
Este repositorio contiene el desarrollo de una actividad formativa cuyo objetivo es explorar y aplicar las capacidades de GitHub Copilot como herramienta de asistencia para la programación. Se desarrolló un script básico en Python para un sistema de recomendación.

## Documentación del Proceso Paso a Paso

A continuación, se detalla el proceso seguido para la realización de esta actividad:

### Paso 1: Configuración de la cuenta y creación del Repositorio
Se validó el acceso a GitHub Copilot a través de los beneficios educativos (GitHub Student Developer Pack) y la capa gratuita de la plataforma. Posteriormente, se creó un nuevo repositorio privado llamado `AI_Project`, inicializándolo con este archivo `README.md`.

### Paso 2: Clonación del Repositorio Localmente
Utilizando la terminal integrada de Visual Studio Code, se procedió a clonar el repositorio en el equipo local mediante el comando:
`git clone https://github.com/tu_usuario/AI_Project.git`
Luego, se ingresó al directorio del proyecto usando el comando `cd AI_Project`.

<img width="1040" height="167" alt="image" src="https://github.com/user-attachments/assets/de809691-0f70-4126-b1fc-f3675c1b4adf" />

### Paso 3: Creación del Script y Uso de GitHub Copilot
Dentro del entorno de Visual Studio Code, se creó el archivo `recommendation_system.py`. Se activó la extensión de GitHub Copilot y se procedió a generar el código del sistema de recomendación utilizando prompts a través de comentarios en el código, tales como:
* `# Importar las librerías necesarias`
* `# Cargar los datos`
* `# Preprocesamiento de datos`
* `# Dividir los datos en conjuntos de entrenamiento y prueba`
* `# Crear y entrenar el modelo`

Copilot sugirió exitosamente las estructuras de código, importando librerías como `numpy`, `pandas` y `scikit-learn`, las cuales fueron aceptadas e integradas al script.

<img width="1180" height="563" alt="image" src="https://github.com/user-attachments/assets/3c79f4df-2dc2-420f-9e4b-2080624ca1d3" />


### Paso 4: Control de Versiones y Subida a GitHub
Una vez completado el código y documentado el proceso en este archivo README, se procedió a guardar los cambios y subirlos al repositorio remoto utilizando los siguientes comandos en la terminal:
1. `git add .`
2. `git commit -m "Add recommendation system example"`
3. `git push -u origin main`

La utilización de GitHub Copilot agiliza significativamente la escritura de código, sugiriendo librerías y estructuras lógicas adecuadas basándose únicamente en instrucciones en lenguaje natural proporcionadas mediante comentarios.
